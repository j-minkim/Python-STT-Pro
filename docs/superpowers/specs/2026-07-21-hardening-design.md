# 완성도 강화 (Hardening) 설계

날짜: 2026-07-21
상태: 승인됨 (안정성 + UI + 품질 자동화 + 테스트·실행환경 전 영역)

## 1. 안정성

- **잡 레지스트리 영속화** (`job_store.py`): 잡 메타데이터(상태, 파일 목록, 다운로드 경로,
  QA 리포트, 재실행용 소스 정보)를 `data/jobs/<job_id>.json`에 원자적으로 저장.
  세그먼트 본문은 저장하지 않음(용량). 서버 시작 시 미완료 잡은 `interrupted`로 표시.
- **작업 큐**: 워커 스레드 1개가 잡을 순차 실행. 동시 제출은 대기열에 쌓이고
  "대기 중 (앞에 N개)" 상태 표시. Whisper 모델 중복 로드로 인한 메모리 폭발 방지.
- **자동 정리**: 시작 시 + 6시간마다 — `data/uploads` 7일, `data/outputs` 30일 경과분
  삭제(환경변수로 조정: `UPLOAD_RETENTION_DAYS`, `OUTPUT_RETENTION_DAYS`).
  만료된 잡은 레지스트리에 `expired` 표시. 24시간 지난 GDrive 폴더 세션 정리.

## 2. UI 완성도

- **이벤트 히스토리 + 재연결**: 잡별 이벤트를 메모리에 보관(세그먼트 이벤트는 최근
  300개로 캡)하고 SSE는 커서 기반 재생으로 전환. 새로고침해도 진행 중 작업에
  자동 재연결되어 이어서 표시. 완료된 잡도 다시 열람 가능.
- **실제 진행률**: 배치 시작 시 PyAV 메타데이터로 각 파일 길이를 읽어
  (완료된 길이 + 현재 파일 진행 위치) / 전체 길이 로 퍼센트 계산.
- **작업 기록 화면**: 최근 잡 목록(상태 배지, 시간, 다운로드 링크, 재전사 버튼).

## 3. 품질 자동화

- **`qa_checks.py`**: 반복 환각 감지(동일 토큰 반복 세그먼트) + 언어 자동감지
  신뢰도 검사 로직을 공용 모듈로. `scripts/find_hallucinations.py`도 이를 재사용.
- **배치 종료 시 자동 QA**: 잡 결과를 스캔해 이상 파일 리포트를 저장·표시
  (`qa` SSE 이벤트). UI에 "이상 N개" 요약 표시.
- **원클릭 재전사** (`POST /api/requeue/<job_id>`): 레지스트리에 저장된 소스 정보로
  같은 배치를 재실행. `only_flagged`면 QA 이상 파일만 manifest에서 제거 후 재실행
  (큐 덕분에 실행 중 배치와 manifest 충돌 없음).

## 4. 테스트·실행환경

- **엔드포인트 테스트** (`tests/test_web_endpoints.py`): 가짜 엔진을 주입해 모델 없이
  제출→완료→다운로드→QA→재전사 흐름과 큐 동작을 검증.
- **waitress**: 설치되어 있으면 프로덕션 WSGI 서버로 서빙(Windows 호환), 없으면
  기존 Flask 개발 서버로 폴백. requirements에 추가.
- **run.sh / run.bat**: `run.sh web` / `run.bat web`으로 웹 서버 실행 지원.

## 호환성 원칙

- 기존 이어하기 manifest·출력 파일 형식은 그대로 유지 (마이그레이션 불필요).
- Windows/macOS 동작 동일 (경로·인코딩 규칙은 기존 스펙 준수).
