# 전역 완료 인덱스 + 사용성 4종 설계

날짜: 2026-07-22
상태: 승인됨 (우선순위: ① 상위 폴더 증분 전사 ② 결과물 자동 폴더 정리 ③ AI 상담 요약 ④ 전사 검색)

## ① 상위 폴더 증분 전사 — 전역 완료 인덱스

문제: 이어하기 기록이 "제출한 폴더 경로" 단위라, 상위 폴더로 제출하면 하위 폴더에서
이미 완료한 파일도 전부 재전사된다.

설계:
- `data/batch_state/global_index.json` 하나로 통합. 파일 키 =
  `NFC(normcase(realpath(절대경로)))|크기|수정시각`. 어느 폴더 기준으로 제출하든
  같은 파일은 같은 키.
- GDrive 키(`gdrive:<id>`, `gdrive-name:...`)는 경로와 무관하므로 그대로 수용.
- 옵션(diarize/summary 등) 일치해야 스킵하는 규칙 유지.
- **마이그레이션**: 첫 로드 때 기존 `dir:` manifest들의 상대경로 키를 소스 폴더와
  합쳐 절대경로 키로 변환해 흡수하고, 원본은 `.migrated`로 보존. `url:` manifest의
  gdrive 키도 흡수. `list:`(CLI 목록 파일) 키는 절대경로 복원이 불가하므로 제외.
- `--fresh`/"완료 기록 무시"는 해당 폴더 경로 프리픽스 아래 항목만 삭제.
- QA 재전사(reset_files)는 표시 이름(상대경로)이 절대경로 키의 끝부분과 일치하는
  항목 삭제.
- 중복 실행 가드 확장: 제출 폴더와 진행/대기 중 작업 폴더가 **포함 관계**여도 거부.

## ② 결과물 자동 폴더 정리

- 로컬 폴더 배치의 다운로드 사본을 파일의 **원본 위치 기반 폴더**에 자동 저장:
  대상 폴더명 = 조상 폴더명에서 찾은 연도(20xx) + "년_" + 파일의 직속 폴더명
  (예: `.../컨설팅 영상_2025/9월_고1/x.mp4` → `~/Downloads/2025년_9월_고1/`).
  연도가 폴더명에 이미 있으면 그대로, 못 찾으면 직속 폴더명만 사용.
- 업로드·GDrive 소스는 기존대로 다운로드 루트에 저장.
- `STT_DOWNLOADS_DIR` 환경변수로 저장 루트 재정의 가능(테스트·사용자 설정용).

## ③ AI 상담 요약 리포트

- `report_summarizer.py`: translator와 같은 백엔드 패턴(openai/lmstudio).
  긴 전사는 청크 분할 → 부분 요약 → 최종 종합(map-reduce).
- 프롬프트: 입시 컨설팅 상담 요약 — 상담 주제, 학생 현황, 컨설턴트 조언·결정사항,
  후속 액션 아이템을 한국어 마크다운으로.
- 산출물: `<이름>.summary.md` (outputs + 다운로드 정리 폴더), 다운로드 URL(`summary`).
- 웹 UI 체크박스 "AI 상담 요약" + 백엔드 선택(기존 번역 엔진 선택 재사용).
- 요약 실패는 파일 실패로 치지 않고 경고 후 계속(전사 결과는 보존).
- 요약 옵션도 이어하기 옵션에 포함(요약 없이 완료한 파일은 요약 켜면 재처리).

## ④ 전사 내용 검색

- `GET /api/search?q=` : outputs의 파일별 최신 전사본에서 세그먼트 텍스트를
  대소문자 무시(NFC)로 검색. 결과 = 파일명, 시각(mm:ss), 매칭 문장, 다운로드 링크.
  결과 상한 200건. 파일 수 규모(수백)에서는 요청 시 스캔으로 충분.
- 웹 UI 검색 카드: 입력 → 결과 리스트(파일명·타임스탬프·하이라이트).

## 테스트

- 전역 인덱스: 하위 폴더 완료 → 상위 폴더 제출 시 전부 스킵(핵심 수락 기준),
  마이그레이션, fresh 프리픽스 삭제, 옵션 불일치 재처리.
- 자동 정리: 폴더명 규칙 단위 테스트 + 배치 후 대상 폴더 생성 확인.
- 요약: 가짜 백엔드로 청크·산출물·실패 경고 검증.
- 검색: API 매칭·상한·한글 NFC 검증.
